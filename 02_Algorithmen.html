So gehst du vor Prüfungskern – 9/9 – alle

  1. Signatur lesen: Was kommt hinein (Parameter), was muss heraus? integer → Zähler oder Summe, double → Durchschnitt, List → Filter, Array → „je Index“, Objekt → Suche/Minimum, void → vorhandene Objekte per Setter ändern.
  2. Beispieldaten von Hand durchrechnen. Wenn du das erwartete Ergebnis der Beispieltabelle nicht selbst ausrechnen kannst, hast du die Aufgabe noch nicht verstanden.
  3. Muster wählen (eins oder mehrere der fünf oben, dazu Minimum/Maximum aus ALG-03).
  4. Variablen vor der Schleife anlegen und initialisieren. Bei verschachtelten Schleifen: Was gilt für alle Durchläufe (außen anlegen), was nur für ein äußeres Element (innen zurücksetzen)?
  5. Schleife über alle Elemente: zähle i von 0 bis liste.size() - 1 bzw. bis feld.length - 1.
  6. Bedingung mit Gettern formulieren. Jede Bedingung aus dem Aufgabentext einzeln abhaken („nicht defekt“, „im Zeitraum“, „mehr als …“: > oder >=?).
  7. Nach der Schleife: Sonderfälle (Division durch 0, nichts gefunden → null), dann rückgabe.
  8. Schreibtischtest mit zwei, drei Datensätzen aus der Tabelle der Aufgabe.
Typische Fehler
  • Zähler/Summe an der falschen Stelle initialisiert: in der inneren Schleife (wird ständig auf 0 gesetzt) oder nur einmal ganz am Anfang (läuft über alle äußeren Elemente weiter).
  • Ganzzahldivision: summe / anzahl mit zwei integer liefert in Java 7 / 2 = 3. Summe als double führen oder umwandeln ((double) summe / anzahl).
  • Division durch 0, wenn kein Element passt.
  • Off-by-one: zähle i von 0 bis liste.size() greift auf ein Element zu, das es nicht gibt. Richtig: bis liste.size() - 1.
  • rückgabe in der Schleife beendet die Methode beim ersten Treffer. Das ist nur bei einer Suche gewollt.
  • = (Vergleich) und := (Zuweisung) verwechselt; Attribut direkt statt über den Getter gelesen.
  • Ergebnisobjekt zwar erzeugt, aber nicht mit add in die Liste gelegt, oder Liste/Array am Ende nicht zurückgegeben.

Eindimensionales Array Prüfungskern – 8/9 – alle außer S26

  • Feste Anzahl von Elementen eines Datentyps, festgelegt beim Anlegen: new integer[24]. Die Größe kann sich danach nicht mehr ändern.
  • Index von 0 bis length − 1. Ein Array mit 24 Elementen hat die Indizes 0 … 23.
  • Neu angelegte Zahlen-Arrays sind in Java mit 0 gefüllt (Objekt-Arrays mit null). In Pseudocode schreibst du die Vorbelegung zur Sicherheit dazu, wenn du dich darauf verlässt.
  • Zugriff auf einen ungültigen Index führt in Java zur ArrayIndexOutOfBoundsException, das Programm bricht ab (siehe ALG-07).
  • Nachbarelemente (Differenz zwischen Element i und i + 1, wie die Fahrzeit zwischen zwei Haltestellen in W24): Die Schleife darf dann nur bis length - 2 laufen, sonst greift feld[i + 1] im letzten Durchlauf ins Leere.

Wichtig ist die Reihenfolge der Bedingungen: erst den Index prüfen, dann zugreifen. Bei und wird der zweite Teil nicht mehr ausgewertet, wenn der erste falsch ist (Kurzschlussauswertung). Bit, Byte und die zwei Arten von Präfixen Kam vor – 2/9 – S26, W23

  • 1 Bit = kleinste Einheit (0 oder 1). 1 Byte = 8 Bit. Mit n Bit lassen sich 2ⁿ verschiedene Werte darstellen (vorzeichenlos 0 … 2ⁿ − 1; mit Vorzeichen −2ⁿ⁻¹ … 2ⁿ⁻¹ − 1). Beispiel 10 Bit: 1 024 Werte.

Eine Exception (Ausnahme) ist ein Objekt, das einen Fehlerzustand beschreibt. Sie wird an der Fehlerstelle geworfen (throw) und wandert die Aufrufkette hinauf, bis ein passender catch-Block sie fängt.
